PolyMind

A local-first multilingual assistant for studying, summarizing, and asking questions about your documents.

This GitHub Pages site is informational only. GitHub Pages serves static files; it cannot run PolyMind's Next.js API routes or an Ollama model. This page does not connect to a public or local AI backend.

Run the full app locally

Chat, conversation history, multilingual responses, PDF extraction and question answering, summaries, exam notes, and flashcards require the Next.js app and Ollama running on your own computer. Model quality and language accuracy depend on the selected local model.

  1. Install Node.js 20.9 or newer and Ollama.
  2. Clone the repository and install its npm dependencies.
  3. Pull the chat and embedding models listed in the project README.
  4. Start the app with npm.cmd run dev on Windows or npm run dev elsewhere.

MCQ generation is not implemented in the current app. Image understanding and scanned-PDF OCR are not included.
